# Qwen3.8-Flash-Next self-generated calibration data: chat

Part of the calibration data of the self-calibrated EXL3 quant of
[Qwen/Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next)
([Vemloir/Qwen3.8-Flash-Next-sc-exl3](https://huggingface.co/Vemloir/Qwen3.8-Flash-Next-sc-exl3)). The full set has three
parts: [agents](https://huggingface.co/datasets/Vemloir/Qwen3.8-Flash-Next-calib-agents),
[chat](https://huggingface.co/datasets/Vemloir/Qwen3.8-Flash-Next-calib-chat) and
[multimodal](https://huggingface.co/datasets/Vemloir/Qwen3.8-Flash-Next-calib-multimodal), ~1.0M tokens together.

Chat conversations, single- and multi-turn, across science, math, code, writing, everyday questions, ML
and music notation.

| Language: en / ru / zh / es / de / it / fr / ko / ja | 67 / 28 / 8 / 3 / 2 / 1 / 1 / 1 / 1 | |

Fields: `reasoning`, `multi_turn`, `prompt_source`, `lang` (of the first prompt).

## Files

- `data.jsonl`: one line per row. `id`, `tokens`, the metadata fields below, `text` (the row decoded with the
  Qwen3.8 chat template's special tokens) and `input_ids`.
- `cal_trace.safetensors`: the same rows in exllamav3 `convert.py --cal_data` format (`input_ids` right-padded to
  the longest row, `lengths`).

Every row was generated by Qwen3.8-Flash-Next itself (an EXL3 4.05 bpw quant) at one of four reasoning levels:
`xhigh`, `medium`, `low` or `off`, set through the chat template.

# Qwen3.8-Flash-Next EXL3, self-calibrated

EXL3 quants of [Qwen/Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next), converted from BF16 with
calibration data generated by the model itself: coding-agent sessions, chats in Russian and English at four reasoning
levels, images. At the same size as turboderp's 4.05 bpw quant, **12-17% lower KL divergence from BF16** on two
independent traces that played no part in calibration.

| Branch | Bits per weight | Head | Vision | Model files | n-gram table | Requires |
|---|---|---|---|---|---|---|
| [4.05bpw_sc_h8_ng8](https://huggingface.co/Vemloir/Qwen3.8-Flash-Next-sc-exl3/tree/4.05bpw_sc_h8_ng8) | 4.05 (4.0498) | 8 bpw | 8 bpw | 69 GB | 52 GB, 8 bpw | exllamav3 >= 1.6.1 |

```
hf download Vemloir/Qwen3.8-Flash-Next-sc-exl3 --revision 4.05bpw_sc_h8_ng8 --local-dir Qwen3.8-Flash-Next-sc-exl3-4.05bpw
```

## Results

KL divergence of the output distribution against BF16, measured with exllamav3 qbench, teacher-forced on assistant
turns; lower is closer to the full model. The reference is turboderp's
[4.05bpw_h6_ng6](https://huggingface.co/turboderp/Qwen3.8-Flash-Next-exl3/tree/4.05bpw_h6_ng6), the same size.

| NVIDIA Nemotron 3.5 Super post-training conversations | 48 | 23k | **0.00796** | 0.00909 | **-12.4%** [-18.6%, -6.2%] | 38 / 48 |
| Multilingual (Russian + 9 languages) | 52 | 26k | **0.00544** | 0.00655 | **-16.9%** [-24.6%, -10.1%] | 41 / 52 |

Intervals come from a paired bootstrap over rows. Perplexity is unchanged within noise: 1.9309 against 1.9316 on the
Nemotron trace (BF16 1.9285), 2.3452 against 2.3443 on the multilingual one (BF16 2.3420).

![Distribution of per-token KL divergence for both quants on both traces](assets/kld_hist.png)

The same comparison token by token: the bulk of the distribution is shifted slightly left and the tail of large
errors (right of 1e-2) is thinner. Medians: 8.6e-4 against 1.07e-3 (Nemotron), 9.3e-4 against 1.16e-3
(multilingual). Unlike turboderp's histograms, there is no noise-floor curve: it needs a separate BF16 run with
injected noise.

Caveats: the head is 8 bpw here against 6 in turboderp's quant (+~150 MB, outside the bits-per-weight budget in
both), and part of the gain comes from it. Calibration data, bit allocation, expert Hessians, head and exllamav3
version all differ from the reference at once, so the gain is not attributed to any one of them. Outside Russian
there are only 4 rows per language; the per-language numbers are indicative.

## What is different

- **Self-generated calibration** (~1M tokens): 20 agent sessions in Docker (Codex, OpenCode and pi harnesses on
  MiMo tasks), 112 chats (25% Russian), 48 image prompts (charts, documents, frontend screenshots, photos) run
  through the vision tower; reasoning levels mixed as xhigh 40%, medium 20%, low 15%, off 25%.
- **Measured bit split in the experts**: in layers 0-9 the routed experts' down projection gets more bits than
  gate/up (3/3/5 in layer 0, 3.5/3.5/5 in 1-7 and 9), elsewhere 4/4/4; chosen from the expert output error of every
  2-6 bit combination per layer.
- **Affinity-weighted expert Hessians**: each of the 512 experts per layer is quantized against its own Hessian,
  tokens weighted by the expert's router probability, instead of one Hessian shared by all of them.
- **Dense tensors**: shared experts, attention k/v and the sparse-attention indexer at 8 bpw, GDN out_proj at 7,
  other dense layers at 6; output head and vision tower at 8.

## Running

Tested with TabbyAPI on exllamav3 1.6.2.

| Setup | Value |
|---|---|
| GPU / CPU | RTX 5070 Ti 16 GB, Ryzen 9 9950X |
| Context | 262,144 tokens |
| Expert layers on CPU | 45 of 48 (`--cpu-moe-offload-layers 45`; with 44 the cache does not fit) |
| VRAM in use | ~14.0 GB |
| System RAM in use | ~56 GB |
| Generation | ~33 tokens/s |
| n-gram table | streamed from disk by default (`ngram_ram: false`), does not need to fit in RAM |

With exllamav3 >= 1.6, do not set `EXL3_GR_MIX_TILED=0`: it keeps extra copies of the hyper-connection tables in
VRAM and the model no longer fits.

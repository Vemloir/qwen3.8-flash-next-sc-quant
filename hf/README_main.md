# Qwen3.8-Flash-Next EXL3, self-calibrated

EXL3 quants of [Qwen/Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next) converted from BF16 with
calibration data generated by the model itself (agent sessions, chats at four reasoning levels, images).

| Branch | Bits per weight | Head | KL divergence vs BF16, independent traces |
|---|---|---|---|
| [4.05bpw_sc_h8](https://huggingface.co/Vemloir/Qwen3.8-Flash-Next-exl3/tree/4.05bpw_sc_h8) | 4.05 | 8 | -12.4% (Nemotron conversations) and -16.9% (multilingual) against turboderp's 4.05 bpw |

Details, results and caveats are in each branch's README. Calibration and evaluation data:
[Vemloir/Qwen3.8-Flash-Next-exl3-calib](https://huggingface.co/datasets/Vemloir/Qwen3.8-Flash-Next-exl3-calib).

Requires exllamav3 >= 1.6.1. The per-layer n-gram table (`ngram_embedding.safetensors`) is not included; see the
branch README.

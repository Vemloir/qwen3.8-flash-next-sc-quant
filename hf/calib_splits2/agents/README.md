# Qwen3.8-Flash-Next self-generated calibration data: agent sessions

Part of the calibration data of the self-calibrated EXL3 quant of
[Qwen/Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next) ([Vemloir/Qwen3.8-Flash-Next-sc-exl3](https://huggingface.co/Vemloir/Qwen3.8-Flash-Next-sc-exl3)). The full set has three parts: [agents](https://huggingface.co/datasets/Vemloir/Qwen3.8-Flash-Next-calib-agents), [chat](https://huggingface.co/datasets/Vemloir/Qwen3.8-Flash-Next-calib-chat), [multimodal](https://huggingface.co/datasets/Vemloir/Qwen3.8-Flash-Next-calib-multimodal),
2,151,377 tokens together. These are the rows that went into calibration; all generated rows (5.0M tokens, a
superset of these) are in [Vemloir/Qwen3.8-Flash-Next-traces](https://huggingface.co/datasets/Vemloir/Qwen3.8-Flash-Next-traces).

Whole agent sessions: each row is the full conversation of one session, from the system prompt and tool
definitions through every model turn and tool result. The tasks come from the MiMo-V2.6-RL-oss agent environments;
the sessions were run in Docker by three coding-agent harnesses talking to the model through an OpenAI-compatible
API, one fresh task per session.

|---|---|---|
| Total | 17 | 1,099,122 |
| xhigh / medium / low / off | 9 / 4 / 2 / 2 | 450,815 / 175,593 / 125,932 / 346,782 |

| Longest session |  | 200,863 |

Fields: `task` (task id of this set), `domain`, `harness`, `reasoning`, `requests` (model calls in the session).

## Files

- `data.jsonl`: one line per row. `id`, `tokens`, the metadata fields above, `text` (the row decoded with the
  Qwen3.8 chat template's special tokens) and `input_ids`.
- `cal_trace.safetensors`: the same rows in exllamav3 `convert.py --cal_data` format (`input_ids` right-padded to
  the longest row, `lengths`).

Every row was generated by Qwen3.8-Flash-Next itself, served as NVIDIA's
[FP4-Local](https://huggingface.co/nvidia/Qwen3.8-Flash-Next-FP4-Local) checkpoint in vLLM, with no output length cap, at one
of four reasoning levels (`xhigh`, `medium`, `low`, `off`, set through the chat template), and checked for
truncated reasoning, loops and language slips (`regen/qa.py` in the
[code repository](https://github.com/Vemloir/qwen3.8-flash-next-sc-quant)); rejected records are not included.

## Versions

This is calibration set 2 (2026-10-18), used by the current version of the quant. Set 1 (~1M tokens, used by the
first version) is the earlier revision `d6646fe56444293cc1706388b9b12fbece877a65` of this repository, kept only so that the first version can
be reproduced: it has reasoning cut off at a 3,072-token limit, a few looping answers and agent sessions truncated
at 25k tokens, and is not meant for any other use.
